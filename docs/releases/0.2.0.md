# Reedline AI 0.2.0 — 原生 Shell 体验预览版

这一版改善 Bash 的请求、预览、插入和取消体验，并让 Bash、PowerShell、
Nushell 优先使用各自已加载的本地历史。已将 v0.1.0 发布分支合回 main，
保留首次配置、单行 init、流式预览和显式本地工作流功能。

## 主要变化

- Bash 重复按 **Ctrl-x Ctrl-g** 即可请求 → 预览 → 插入；
  **Ctrl-x Ctrl-k** 取消 AI 并保留输入。中文预览直接显示。
- 最近 200 条原生历史在本地做前缀／后缀匹配，命中不调用模型。
  不会在首次使用时把整份历史上传；Bash 体验启动器只读历史文件，不写回。
- Bash 兼容范围扩展到 **4.3+**，修复旧版本 Unicode 光标、prompt 和
  按键恢复问题，以及 Bash 5.3 的绑定输出格式变化。
- PowerShell 增加 **5.1 / PSReadLine 2.0** 兼容路径；该 Windows 组合
  尚未原生实测，不能视为认证兼容。
- 新增临时 Bash 体验入口、真实终端 E2E，以及本地 macOS 打包脚本。

## 下载和使用

本次附带 **macOS Apple Silicon（arm64）** 程序包、源码包和 SHA256 校验值。
macOS 包解压后运行：

```sh
./bin/reedline-ai --complete 'git st'
bash scripts/try-bash.sh
```

体验启动器需要 Bash 4.3+ 和 Python 3.9+。macOS 自带 Bash 3.2 不支持，
可自行安装新版 Bash（例如 `brew install bash`）；启动器会查找 Homebrew 路径。
默认离线 mock，不修改 profile。使用环境中的 `DEEPSEEK_API_KEY` 时，显式运行
`bash scripts/try-bash.sh --deepseek`，模型为 `deepseek-flash`。
其他服务可使用 `./bin/reedline-ai setup` 后按安装指南启用。

Linux、Windows 和 Intel Mac 本次提供源码构建入口，**没有附带这些平台的新二进制**：
在源码根目录安装固定 Rust 工具链后运行 `cargo install --path . --locked`。
v0.1.0 的 Linux／Windows 附件仍保留在旧版发布页，它们不包含本次优化。
macOS 包未公证；manifest 中的最低系统版本只反映二进制部署目标，不代表
在所有 macOS 版本上完成测试。

## 验证范围

发布检查在 macOS 26.6 arm64 上完成，使用真实 PTY 和原生编辑器：
Bash、PowerShell 7.4.6 / PSReadLine 2.3.5、Nushell 0.116.1。
覆盖请求、预览、插入、撤销、取消、编辑期间过期结果、历史冷启动以及
干净 HOME 中安装／禁用／卸载。另有用户授权的官方 DeepSeek 实际请求验证。
具体版本、结果和边界见随包 `docs/VALIDATION.md`。

这仍是预览版：原生 Bash 是显式按键触发，并非自动行内灰字；没有声称整体
体验已经超过 Nushell。Windows 5.1、Git Bash／WSL 和各类终端仍需独立验证。
接受只改写编辑行，不替用户按 Enter；本机 Shell 在用户按 Enter 后仍会正常执行。
